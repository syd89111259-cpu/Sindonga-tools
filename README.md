# 🏠 신동아부동산 도구함

신동아공인중개사사무소 실무 도구 모음. GitHub Pages로 열리는 한 장짜리 페이지입니다.

- 주소: https://syd89111259-cpu.github.io/shindonga-tools/
- 지금 있는 도구: **📊 실거래가 카드 생성기** — 국토교통부 아파트 매매 실거래가를 불러와 카톡·블로그용 카드 이미지(PNG)와 SNS 글을 만듭니다.

## 쓰는 법

1. 위쪽 탭에서 도구를 고릅니다.
2. 처음 한 번은 오른쪽 위 **🔑 API 키 설정**에 공공데이터포털 인증키를 저장합니다.
3. `실거래 API` 탭에서 지역·계약년월을 고르고 **불러오기** → 목록에서 카드에 넣을 거래를 체크 → **PNG 다운로드** 또는 **이미지 복사**.
4. API를 쓰지 않을 때는 `XML / CSV 붙여넣기`(공공데이터포털 응답을 그대로)나 `직접 입력`으로도 카드를 만들 수 있습니다. 이 두 가지는 키 없이 동작합니다.

## API 키 (중요)

- 이 저장소에는 **어떤 API 키도 들어 있지 않습니다.** 소스가 공개되어 있어도 키는 새지 않습니다.
- 키는 그 브라우저의 `localStorage`에 `shindonga.apiKey.dataGoKr` 이름으로만 저장되고, 페이지 코드나 서버로 보내지 않습니다. 화면에는 끝 4자리만 마스킹해서 보여 줍니다.
- 조회할 때만 국토교통부 API(`apis.data.go.kr`)로 전송됩니다.
- 다른 기기·다른 브라우저·시크릿 모드에서는 다시 입력해야 합니다. 공용 PC에서는 **저장된 키 삭제**를 눌러 주세요.
- 공개 저장소에 키를 올리지 마세요. 실수로 올렸다면 파일에서 지우는 것만으로는 부족하고, 공공데이터포털에서 해당 인증키를 재발급(변경)하는 것이 가장 확실합니다. (공개 저장소의 과거 커밋은 계속 남습니다.)

## 인증키 발급

공공데이터포털 → [국토교통부_아파트 매매 실거래가 상세 자료](https://www.data.go.kr/data/15058708/openapi.do) → 활용신청 → 일반 인증키(Decoding)

## 도구 추가하기

`index.html` 안에서 두 군데만 더하면 새 도구가 붙습니다.

1. 위 탭(`<nav class="nav">`)에 버튼 한 줄: `<button class="navbtn" data-view="도구이름" aria-selected="false">🧾 새 도구</button>`
2. 본문에 한 덩어리: `<main class="view" id="view-도구이름"> … </main>`

탭 전환(`switchView`)과 스타일은 이미 붙어 있습니다.

## 배포

`main` 브랜치 루트(`/`)를 GitHub Pages 소스로 씁니다. `main`에 푸시하면 1분 안팎 뒤 자동으로 반영됩니다.
