# 🏠 신동아부동산 도구함

신동아공인중개사사무소 실무 도구 모음. GitHub Pages로 열리는 한 장짜리 페이지입니다.

- 주소: https://syd89111259-cpu.github.io/Sindonga-tools/
- 지금 있는 도구
  - **📊 실거래가 카드 생성기** — 국토교통부 아파트 매매 실거래가를 불러와 카톡·블로그용 카드 이미지(PNG)와 SNS 글을 만듭니다.
  - **🔍 실거래 조회** — 두 가지 방식입니다.
    - **🏢 아실 14개 단지 (동별)** — 가맹점 14개 단지의 **아실 [동/호 실거래가]**(매매·전세·월세 동시 조회)를 아실 화면과 같은 표로 봅니다. 데이터는 암호화해서 배포하고, 비밀번호를 한 번 넣으면 그 브라우저에만 저장됩니다.
    - **🌐 국토부 전체 API** — 국토교통부 실거래가를 **매매 · 전월세(전체) · 전세 · 월세**로 조회합니다. 동별·평형대·단지 필터와 시세 요약, 그리고 조회 결과에서 고른 거래를 카드 생성기로 바로 넘깁니다.

## 쓰는 법

1. 위쪽 탭에서 도구를 고릅니다.
2. 처음 한 번은 오른쪽 위 **🔑 API 키 설정**에 공공데이터포털 인증키를 저장합니다(매매·전월세가 같은 키를 씁니다).
3. `실거래 API` 탭에서 지역·계약년월을 고르고 **범위**(최근 3개월 · 1년 · 3년 · 5년 · 10년 · **기간 직접 지정**)를 정한 뒤 **불러오기** → 목록에서 카드에 넣을 거래를 체크 → **PNG 다운로드** 또는 **이미지 복사**.
   - **기간 직접 지정**은 시작월~끝월을 달력에서 고릅니다(최대 120개월 = 10년, 넘으면 끝월 기준으로 자동 보정). 여러 달을 불러오는 동안 `(12/36개월)`처럼 진행 상황이 표시됩니다.
   - 3년·5년·10년처럼 긴 범위는 시간이 걸리므로 **중단** 버튼으로 지금 받는 달까지만 받고 멈출 수 있습니다(받은 데까지 표로 만듭니다).
   - 목록은 한 번에 300건씩 보이고 **목록 더 보기**로 이어서 봅니다. `평형별 최고가`·`상위 6건`은 화면에 보이는 300건이 아니라 불러온 거래 전체(최대 12,000건)를 기준으로 계산합니다.
4. API를 쓰지 않을 때는 `XML / CSV 붙여넣기`(공공데이터포털 응답을 그대로)나 `직접 입력`으로도 카드를 만들 수 있습니다. 이 두 가지는 키 없이 동작합니다.

### 🔍 실거래 조회

탭 위쪽 **`🏢 아실 14개 단지 (동별)` / `🌐 국토부 전체 API`** 로 조회 방식을 고릅니다. 처음 열면 아실(동별) 방식이 선택되어 있습니다.

#### 🏢 아실 14개 단지 (동별)

1. 처음 한 번은 **🔐 아실 데이터 비밀번호**를 넣고 **열기**를 누릅니다. 맞으면 이 브라우저의 `localStorage['shindonga.asilPass']`에 저장되어 다음부터 자동으로 열립니다. 틀리면 **“비밀번호가 맞지 않습니다”** 가 나오고 열리지 않습니다.
   - 공용 PC에서는 **🔒 잠금**으로 저장된 비밀번호를 지웁니다. **비밀번호 변경**은 저장된 비밀번호를 지우고 다시 입력하게 합니다.
2. **단지 버튼 바** — `목련9단지` ~ `평촌엘프라우드` 14개 + `전체 단지` + `초기화`(모든 조건을 처음 상태로).
3. **거래유형 체크** — `매매`(파랑) `전세`(빨강) `월세`(초록) 을 한 표에서 동시에 보거나 끕니다.
4. **필터** — 기간(최근 3개월 · 1년 · 3년 · 5년 · 10년 · 직접 지정), 면적(고른 단지의 실제 평형 목록), 동(고른 단지의 실제 동 + `동 미상`), 정렬(최근순 · 과거순 · 동·층별 · 높은 가격순). 바꾸면 바로 반영됩니다.
   - 지금 배포된 자료는 **10년치(2016.11 ~ 2026.11)** 입니다. 그래서 3년·5년·10년을 골라도 실제로는 이 기간만 보이고, 범위 밖을 고르면 "지금 보유한 아실 실거래 자료는 2016.11 ~ 2026.11까지입니다" 안내가 함께 나옵니다(자료가 늘면 그만큼 보입니다).
5. **표** — `체크(매매) · 동 · 층 · 면적(평) · 면적(㎡) · 계약일 · 구분(신규/갱신/-) · 계약기간 · 거래 · 체결가격`. `전체 단지`에서는 단지명이 함께 나오고, 계약일 옆 동그라미는 계약일로부터 지난 날수입니다.
6. 요약 바에 총 건수(매매/전세/월세 각 건수), 최근 거래, 업데이트 기준 시각이 나옵니다.
7. 매매 행을 **최대 8건 체크**하고 **선택 건 카드로 만들기** → 1번 탭 카드 생성기로 넘어갑니다.

> 데이터는 아실 가맹점 관리자 실거래가를 받아 `asil_data.enc`(AES-256-GCM · PBKDF2-HMAC-SHA256 100,000회)로 **암호화해서만** 배포합니다. 저장소에는 평문 데이터도, 비밀번호도, API 키도 들어 있지 않습니다. 비밀번호를 잊으면 데이터를 열 수 없고, 다시 배포할 때 새로 암호화해야 합니다.

#### 🌐 국토부 전체 API

1. **거래 유형**(매매 / 전월세(전체) / 전세 / 월세)을 고릅니다.
2. 지역 프리셋과 **기간**(최근 3개월 · 1년 · 3년 · 5년 · 10년 · 직접 지정, 최대 120개월)을 정하고 **불러오기**.
   - 한 달에 1,000건이 넘으면 자동으로 다음 페이지까지 받아 옵니다.
   - 긴 범위(3년 36회 · 5년 60회 · 10년 120회 호출)는 **중단** 버튼으로 멈출 수 있고, `불러오는 중 12/60개월`처럼 진행이 표시됩니다.
   - 매매는 해제된 거래를 자동으로 빼고, 직거래·등기 여부를 표시합니다.
3. **내 관심 아파트** 칩으로 단지를 빠르게 부릅니다(쉼표·슬래시·공백으로 여러 개, `목련 N단지`로 이름 통일). `+ 현재 검색 저장`으로 지금 검색어를 칩으로 남기고, ×로 지웁니다.
4. **동별 필터(매매)** — 결과에 있는 동이 자동으로 칩이 됩니다. 동을 고르면 등기 전(동 공백) 최신 계약을 **`동 미공개(등기전) 함께 보기`** 로 넣거나 뺄 수 있습니다. 전월세는 국토부 정책상 동 정보가 없어 대신 **계약구분(전체/신규/갱신)** 으로 봅니다(종전 금액·갱신요구권 사용 배지 표시).
5. **평형대**(전체 / 20평 미만 / 20평대 / 30평대 / 40평대 / 50평대)와 **정렬**(최신순 · 높은 가격순 · 낮은 가격순 · 동·층순)로 좁힙니다. 위 요약 바에 건수·최근 거래가·최고가·최저가(전월세는 보증금)가 나옵니다.
6. 매매 결과에서 최대 8건을 체크하고 **선택 건 카드로 만들기** → 카드 생성기 탭에서 그 거래들이 선택된 채로 카드가 그려집니다.

## 전용 주소로 바로 열기

탭을 누르지 않고 주소만으로 원하는 화면을 열 수 있습니다. 탭이나 조회 방식을 바꾸면 주소창도 `?tab=…` 으로 함께 바뀌므로 그대로 북마크하거나 카톡으로 보내면 됩니다.

| 주소 | 열리는 화면 |
| --- | --- |
| `https://syd89111259-cpu.github.io/Sindonga-tools/` (또는 `?tab=card`, `#card`) | 📊 실거래가 카드 생성기 |
| `…/?tab=asil` (또는 `#asil`) | 🔍 실거래 조회 → 🏢 아실 14개 단지 (동별) |
| `…/?tab=molit` (또는 `#molit`) | 🔍 실거래 조회 → 🌐 국토부 전체 API |

- 아실 모드는 전과 똑같이 비밀번호를 한 번 넣어야 표가 열립니다(주소로 열어도 같습니다).
- `?tab=asil` 처럼 쿼리로 들어오면 첫 진입 때 주소를 고쳐 쓰지 않고, 이미 붙어 있는 다른 파라미터도 그대로 둡니다.

## API 키 (중요)

- 이 저장소에는 **어떤 API 키도 들어 있지 않습니다.** 소스가 공개되어 있어도 키는 새지 않습니다.
- 키는 그 브라우저의 `localStorage`에 `shindonga.apiKey.dataGoKr` 이름으로만 저장되고, 페이지 코드나 서버로 보내지 않습니다. 화면에는 끝 4자리만 마스킹해서 보여 줍니다.
- 조회할 때만 국토교통부 API(`apis.data.go.kr`)로 전송됩니다.
- 다른 기기·다른 브라우저·시크릿 모드에서는 다시 입력해야 합니다. 공용 PC에서는 **저장된 키 삭제**를 눌러 주세요.
- 공개 저장소에 키를 올리지 마세요. 실수로 올렸다면 파일에서 지우는 것만으로는 부족하고, 공공데이터포털에서 해당 인증키를 재발급(변경)하는 것이 가장 확실합니다. (공개 저장소의 과거 커밋은 계속 남습니다.)

## 도구 추가하기

`index.html` 안에서 두 군데만 더하면 새 도구가 붙습니다.

1. 위 탭(`<nav class="nav">`)에 버튼 한 줄: `<button class="navbtn" data-view="도구이름" aria-selected="false">🧾 새 도구</button>`
2. 본문에 한 덩어리: `<main class="view" id="view-도구이름"> … </main>`

탭 전환(`switchView`)과 스타일은 이미 붙어 있습니다.
