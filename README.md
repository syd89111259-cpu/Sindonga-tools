# 🏠 신동아부동산 도구함

신동아공인중개사사무소 실무 도구 모음. GitHub Pages로 열리는 한 장짜리 페이지입니다.

- 주소: https://syd89111259-cpu.github.io/Sindonga-tools/
- 지금 있는 도구
  - **📊 실거래가 카드 생성기** — 국토교통부 아파트 매매 실거래가를 불러와 카톡·블로그용 카드 이미지(PNG)와 SNS 글을 만듭니다.
  - **🔍 실거래 조회** — 국토교통부 실거래가를 **매매 · 전월세(전체) · 전세 · 월세**로 조회합니다. 동별·평형대·단지 필터와 시세 요약, 그리고 조회 결과에서 고른 거래를 카드 생성기로 바로 넘깁니다.

## 쓰는 법

1. 위쪽 탭에서 도구를 고릅니다.
2. 처음 한 번은 오른쪽 위 **🔑 API 키 설정**에 공공데이터포털 인증키를 저장합니다(매매·전월세가 같은 키를 씁니다).
3. `실거래 API` 탭에서 지역·계약년월을 고르고 **범위**(해당 월 · 최근 2·3·6개월 · 최근 1년 · **기간 직접 지정**)를 정한 뒤 **불러오기** → 목록에서 카드에 넣을 거래를 체크 → **PNG 다운로드** 또는 **이미지 복사**.
   - **기간 직접 지정**은 시작월~끝월을 달력에서 고릅니다(최대 24개월, 넘으면 끝월 기준으로 자동 보정). 여러 달을 불러오는 동안 `(3/12개월)`처럼 진행 상황이 표시됩니다.
   - 목록은 한 번에 300건씩 보이고 **목록 더 보기**로 이어서 봅니다. `평형별 최고가`·`상위 6건`은 화면에 보이는 300건이 아니라 불러온 거래 전체(최대 12,000건)를 기준으로 계산합니다.
4. API를 쓰지 않을 때는 `XML / CSV 붙여넣기`(공공데이터포털 응답을 그대로)나 `직접 입력`으로도 카드를 만들 수 있습니다. 이 두 가지는 키 없이 동작합니다.

### 🔍 실거래 조회

1. **거래 유형**(매매 / 전월세(전체) / 전세 / 월세)을 고릅니다.
2. 지역 프리셋과 **기간**(해당 월 · 최근 2·3·6·12개월 · 직접 지정, 최대 24개월)을 정하고 **불러오기**.
   - 한 달에 1,000건이 넘으면 자동으로 다음 페이지까지 받아 옵니다.
   - 매매는 해제된 거래를 자동으로 빼고, 직거래·등기 여부를 표시합니다.
3. **내 관심 아파트** 칩으로 단지를 빠르게 부릅니다(쉼표·슬래시·공백으로 여러 개, `목련 N단지`로 이름 통일). `+ 현재 검색 저장`으로 지금 검색어를 칩으로 남기고, ×로 지웁니다.
4. **동별 필터(매매)** — 결과에 있는 동이 자동으로 칩이 됩니다. 동을 고르면 등기 전(동 공백) 최신 계약을 **`동 미공개(등기전) 함께 보기`** 로 넣거나 뺄 수 있습니다. 전월세는 국토부 정책상 동 정보가 없어 대신 **계약구분(전체/신규/갱신)** 으로 봅니다(종전 금액·갱신요구권 사용 배지 표시).
5. **평형대**(전체 / 20평 미만 / 20평대 / 30평대 / 40평대 / 50평대)와 **정렬**(최신순 · 높은 가격순 · 낮은 가격순 · 동·층순)로 좁힙니다. 위 요약 바에 건수·최근 거래가·최고가·최저가(전월세는 보증금)가 나옵니다.
6. 매매 결과에서 최대 8건을 체크하고 **선택 건 카드로 만들기** → 카드 생성기 탭에서 그 거래들이 선택된 채로 카드가 그려집니다.

## API 키 (중요)

- 이 저장소에는 **어떤 API 키도 들어 있지 않습니다.** 소스가 공개되어 있어도 키는 새지 않습니다.
- 키는 그 브라우저의 `localStorage`에 `shindonga.apiKey.dataGoKr` 이름으로만 저장되고, 페이지 코드나 서버로 보내지 않습니다. 화면에는 끝 4자리만 마스킹해서 보여 줍니다.
- 조회할 때만 국토교통부 API(`apis.data.go.kr`)로 전송됩니다.
- 다른 기기·다른 브라우저·시크릿 모드에서는 다시 입력해야 합니다. 공용 PC에서는 **저장된 키 삭제**를 눌러 주세요.
- 공개 저장소에 키를 올리지 마세요. 실수로 올렸다면 파일에서 지우는 것만으로는 부족하고, 공공데이터포털에서 해당 인증키를 재발급(변경)하는 것이 가장 확실합니다. (공개 저장소의 과거 커밋은 계속 남습니다.)

## 도구 추가하기

`index.html` 안에서 두 군데만 더하면 새 도구가 붙습니다.

1. 위 탭(`<nav class="nav">`)에 버튼 한 줄: `<button class="navbtn" data-view="도구이름" aria-selected="false">🧾 새 도구</button>`
2. 본문에 한 덩어리: `<main class="view" id="view-도구이름"> … </main>`

탭 전환(`switchView`)과 스타일은 이미 붙어 있습니다.
